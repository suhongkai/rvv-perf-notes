# rvv-perf-notes

面向 RISC-V（SpacemiT K1，8×X60，256-bit RVV 1.0）的端侧大模型部署与性能优化实践记录。
以 Qwen3.5-2B / 4B 为载体，覆盖量化配方、RVV 内核改造、线程调度与长上下文管理四个层面，
所有性能数字都绑定可复验的证据文件与 SHA256。

> 本包为完整提交材料：方案书、技术报告、部署与复现、模型与测试集、源码与二进制、证据与复验；不含模型权重（见 `05_模型与测试集` 的网盘链接）。

## 复验（两条命令）

```bash
# 1) 证据链：逐条重算 97 条 claim 并校验证据 SHA256
cd 08_证据与复验 && python tools/verify_claims.py     # 期望 97/97

# 2) 部署自检（板端，需先按 03 编译或解包交付二进制）
cd 03_部署与复现 && bash scripts/verify.sh <模型gguf>
```

## 硬件与软件基线

- 平台：SpacemiT K1（8× X60，RVV 1.0，VLEN=256），8 GB LPDDR4X；
- 工具链：出厂 GCC 13.2，编译需 `apt install gcc-14 g++-14 cmake`；
- 推理框架：`spacemit-com/llama.cpp`，本包含 7 个补丁（详见 `03_部署与复现/patches/`）；
- 构建指纹：`libggml-cpu.so.0.26.0` = `4436a9f4…`（交付二进制与该指纹一致）。
