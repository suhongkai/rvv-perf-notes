# 证据与复验

本目录是提交包内的独立复验入口：97 条 claim 的登记表、全部证据文件与校验脚本均在此，不依赖外部仓库。

---

## 1 目录内容

**表 1 目录内容**

| 路径 | 内容 |
|---|---|
| `claims.json` | 97 条 claim：陈述、证据文件、SHA256、取值表达式、构建标签 |
| `results/` | 证据文件（86 个 JSON：85 个与 claim 一一对应，另 1 个 `multiturn-2026-11-08.json` 是技术报告 §5.6 多轮对话的补充证据，未登记为 claim） |
| `tools/verify_claims.py` | 校验脚本：逐条重算并与登记值比对 |

## 2 复验方式

```bash
cd 08_证据与复验
python tools/verify_claims.py
```

预期输出：

```
97/97 通过，0 条有问题
```

脚本对每条 claim 执行三步：按 `evidence` 找到 `results/` 中的文件；重算 SHA256 并与 `evidence_sha256` 比对；按 `expr` 重新取值并与 `value` 比对。任一环节不符即报错。

## 3 失败时的含义

**表 2 报错类型**

| 输出 | 含义 |
|---|---|
| `MISSING` | `results/` 中缺少证据文件 |
| `SHA-DIFF` | 证据文件被修改或替换 |
| `EXPR-ERR` | 取值表达式无法在证据文件中解析 |
| `VALUE-DIFF` | 证据文件的当前值与登记值不一致 |

出现上述任一情况，说明提交包被改动，应以本目录的 `claims.json` 为准重新核对。

## 4 与文档的对应

技术报告、方案书与部署文档中出现的数字，均可在 `claims.json` 中按 `id` 找到对应条目；文档中的 `C编号` 即 claim 的编号前缀。历史值与当前值通过 `superseded_by` 字段区分，材料不得将历史值作为当前值引用。
