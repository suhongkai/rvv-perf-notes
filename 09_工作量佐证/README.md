# 工作量佐证

本目录是**补充材料**，用于佐证实验规模与工程工作量。所有数字都可由随包文件直接算出。

| 文件 | 作用 |
|---|---|
| `实验台账_INDEX.json` | 307 条实验归档索引，每条含原始文件 SHA256、字节数、任务类别、板数、时间 |
| `台账统计.md` | 由台账直接统计出的规模、任务分布、与随包证据的 SHA256 对应关系 |
| `图源/` | 技术报告 5 幅图与附录 E 的生成脚本（matplotlib 300 dpi），证明图表由数据脚本生成而非手工绘制 |

## 为什么放这些

评分细则里"工程与创新（5%）"与"基础优化完成度（10%）"都涉及**工作量与可复现性**。
与其在正文里声称"做了很多实验"，不如让评委能自己数：台账 307 条、随包证据 86 个、
其中 80 个能与台账按 SHA256 对上。

## 边界

- 本目录**不参与** `claims.json` 的 97 条校验，正文数字仍以 `08_证据与复验/claims.json` 为准；
- 台账中的内网板卡地址已脱敏为 `board-<编号>`；
- 931 个原始结果文件（63.7 MB）未随包，避免提交包过大。
